# Diamond Mine — Escape

A dependency-free, browser-based pixel-art mine escape game.

## Play

Open `index.html` in a modern browser, or serve this directory with any static HTTP server.

- **A / D** — move; **W / Space** — jump or climb up; **S** — climb down
- **Left click** — mine with the pickaxe or fire the selected weapon
- **Right click** — place a collected stone block
- **E** — open a nearby chest; **F / Q** — swing the pickaxe
- **1–6** or the mouse wheel — select an owned weapon

Climb the ladder shafts from the deepest level to the surface. Mine diamonds, loot chests for weapons and supplies, and defeat the Mine Lord to escape.
